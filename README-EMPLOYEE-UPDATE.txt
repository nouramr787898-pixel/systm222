تحديث واجهة الموظف — إحكام الأعمال

- الشريط الجانبي: ملفي الشخصي، أرصدة الإجازات، طلباتي، الحضور والانصراف.
- الملف الشخصي: عرض شامل للبيانات المسجلة للموظف فقط، للقراءة دون إمكانية تعديل.
- استحقاق الإجازات: طلب منفصل حتى لا تظهر صفحة فارغة عند فشل تحميل الأرصدة.
- إن لم يرتبط الحساب بملف موظف تظهر رسالة واضحة بدلاً من الصفحة البيضاء.
- بيانات غير مدعومة في قاعدة البيانات الحالية (مثل رقم الجواز والجنسية وتاريخ الميلاد والفرع ورقم العقد) لا تُختلق ولا تظهر حتى تُضاف من الإدارة.
- لا تغييرات في API تسجيل الدخول أو إرسال OTP.
- مهم: اختبر على نسخة تجريبية؛ قاعدة SQLite الحالية قد لا تكون دائمة على Railway، وتوجد حسابات افتراضية في النسخة الأولية.
