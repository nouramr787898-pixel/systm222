URGENT SECURITY FIX / إصلاح أمني عاجل

عزلت تأكيد رمز OTP في طلب منفصل إلى الخادم قبل فتح نموذج تغيير كلمة المرور.
لا يسمح الخادم بتغيير كلمة المرور إلا بتذكرة تحقق آمنة مؤقتة، لا تستخدم إلا مرة واحدة بعد تحقق Bird/البريد.
الرمز العشوائي لا يفتح شاشة كلمة المرور. بعد خمسة إخفاقات يجب طلب رمز جديد.
استبدل ملفات GitHub بهذه النسخة، وتحقق من وصول تحديث Railway إلى ACTIVE وجرّب رمزًا عشوائيًا في حساب اختبار؛ يجب رفضه.
مهم: هذه معالجة لثغرة واحدة؛ المنصة لا تزال غير جاهزة لحفظ بيانات موظفين حقيقية أو للاستخدام العام بسبب حسابات الاختبار والتخزين غير الدائم وقضايا الحماية الأخرى.
