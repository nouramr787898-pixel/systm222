# بوابة إحكام: تحديث حساب الموظف والاستعادة

## ما أضيف
- المدير عند إضافة موظف يحدد اسم مستخدم فريد وكلمة مرور أولية، ومفتاح جوال +966 أو +20، ورقم الجوال، والبريد الإلكتروني.
- بيانات الحساب تربط بملف الموظف وصلاحياته؛ تُخزّن كلمة المرور عبر PBKDF2 ولا تُعرض بعد حفظها.
- استعادة كلمة المرور للموظف فقط، بوسيلة اختيارية: البريد أو SMS، ورمز تحقق من 6 أرقام صالح 10 دقائق وخمس محاولات تحقق.

## إعداد خدمة الرسائل في Railway > Variables

البريد: SMTP_HOST وSMTP_PORT (افتراضي 587) وSMTP_USER وSMTP_PASSWORD وSMTP_FROM.

SMS عبر Twilio: TWILIO_ACCOUNT_SID وTWILIO_AUTH_TOKEN وTWILIO_FROM_NUMBER.

هذه الإعدادات غير مرفقة لأسباب أمنية؛ **لن تُرسل رسائل فعليًا حتى يضبطها مالك الحساب**. يجب التحقق من ملكية البريد والجوال ومراعاة سياسة الإرسال قبل الاستخدام الواقعي.

## قيود مهمة
- تطبيق تجريبي تقني قيد استكمال الحماية للاستخدام الحقيقي (HTTPS secure cookies, CSRF, جلسات ثابتة وآمنة، سجلات أمان، rate limits موزعة، تخزين دائم، نسخ احتياطية، حماية PII، ومراجعة كاملة للاختبار).
- SQLite الحالي غير مجهز بعد للتخزين الدائم على Railway وقد تُفقد البيانات بعد إعادة النشر. لا تدخل بيانات موظفين حقيقية.
- إعادة نشر الكود وحدها لا تفعل خدمة SMS أو البريد.
