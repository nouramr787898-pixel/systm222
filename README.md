# منصة إحكام الأعمال — تحديث Bird Email + SMS

النسخة تتضمن واجهة رمز التحقق OTP، وتضيف ربطًا منفصلًا لخدمة Bird Email لإرسال رمز إعادة تعيين كلمة المرور من بريد الشركة، مع الإبقاء على Bird Verify لرسائل SMS. هذا تحديث للكود وليس إثباتًا لوصول رسائل فعلية.

## إعداد Railway
- `BIRD_API_KEY`: المفتاح السري لبيئة Bird؛ يُحفظ في Railway Variables فقط.
- `BIRD_FROM_EMAIL`: `info@ehkambusiness.com` (دومين إرسال موثّق في Bird).
- Start Command: `python server.py`
- لا تضع المفاتيح في GitHub أو Railpack build secrets.

## اختبار
- ارفع ملفات ZIP مباشرة إلى جذر مستودع GitHub الخاص بالموقع واستبدل الملفات الأقدم، وتأكد من نشر Railway بنجاح.
- اختبر أولًا بموظف تجريبي له بريد أو رقم جوال ملكك ومخزّن في ملفه، ثم اختر «هل نسيت كلمة المرور؟».
- بريد الموظف: يرسل النظام OTP عبر Bird Email API. الجوال: يطلب Bird Verify إرسال OTP إلى رقم مصر أو السعودية المسجّل.
- إدخال الرمز الصحيح مع كلمة مرور جديدة يؤدي إلى تحديث كلمة المرور وإبطال الجلسات السابقة الموجودة في نفس عملية الخادم.
- يحتاج الحساب صلاحيات Email/emails Write و Verify/verify Write وتفعيل الدول والدفع عند الحاجة.

## تحذيرات قبل الإنتاج
- فحص Python والترابط المحلي لا يمثل اختبارًا حقيقيًا لإرسال البريد/SMS؛ استخدم بريدًا ورقمًا مصرحًا باختبارهما فقط.
- SQLite داخل مجلد المشروع غير مضمون الاستمرار مع إعادة نشر Railway. يجب تهيئة تخزين دائم وترحيل البيانات قبل الاستخدام الحقيقي.
- الحسابات الافتراضية التجريبية ومحدودية حماية الطلبات والجلسات وعدم تحقق جهات اتصال الموظف تجعل التطبيق غير جاهز لبيانات موظفين حقيقية.
- رسائل Bird Email المقبولة ليست بالضرورة مُسلّمة، راجع Bird Email logs وSMS Verify.
- هذا المشروع يحتوي على ملفات المشروع الأساسية؛ حذف الملفات القديمة غير اللازمة يفضل أن يتم بحذر.
