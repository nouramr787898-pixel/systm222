# بوابة إحكام الأعمال — نسخة تشغيل محلية

هذه النسخة **تستخدم خادم Python وقاعدة بيانات SQLite فعلية**؛ التغييرات المدعومة تُحفظ بعد إعادة تشغيل الخادم. ليست عرض GitHub Pages ولا نسخة آمنة للنشر العام.

## التشغيل على Windows
1. ثبّت Python 3.9+، وافتح الطرفية داخل هذا المجلد.
2. نفّذ `python server.py`.
3. افتح `http://127.0.0.1:8765/` على نفس الكمبيوتر.
4. تتولّد قاعدة بيانات `ehkam_data.sqlite3` عند التشغيل الأول؛ احتفظ بنسخ احتياطية منها ولا ترفعها إلى GitHub.

## الحسابات الأولية (للتشغيل المحلي فقط)
| الاختيار | اسم المستخدم | كلمة المرور |
|---|---|---|
| المدير | admin | Admin@123 |
| المشرف | manager | Manager@123 |
| الموظف | employee | Employee@123 |

**غيّر آلية إنشاء الحسابات وكلمات المرور قبل أي نشر؛ بيانات البداية معروفة وغير صالحة للإنتاج.**

## يعمل
- تسجيل دخول بكلمة مرور مع التحقق من الدور، وجلسات داخل الخادم.
- إدارة الشركات والموظفين والطلبات والأرشفة وسجل العمليات في SQLite.
- عزل موظف/مشرف/مدير على مستوى واجهات API.
- قواعد حساب أولية للإجازات والسلف واعتمادات الطلبات وحفظها.
- تصدير CSV وبعض عمليات الحضور وتصحيح البصمة.

## لا يزال غير مكتمل للنشر الحقيقي
- حسابات المستخدمين الجديدة واستعادة كلمة المرور بالهاتف أو البريد، والتفعيل الإلكتروني.
- تحقق بصمة جغرافية آمن، وملفات ومرفقات، ورواتب مالية فعلية وإشعارات SMS/email.
- PDF وExcel الأصلي بدل CSV، تخصيص العطلات الكاملة والمعادلات المالية الدقيقة وترحيل العقود.
- حماية إضافية: CSRF، الحد من محاولات الدخول، الجلسات المخزنة، HTTPS، الاستضافة الدائمة وقاعدة بيانات ونسخ احتياطية مناسبة.
- هذا المشروع لا يعمل على GitHub Pages؛ لا ترفع بيانات الموظفين الحقيقية إليه.
