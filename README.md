# إحكام الأعمال — بوابة الموارد البشرية (نسخة أولية محلية)

تجربة تشغيلية للمرحلة الأولى طبقًا لملف «محتويات بوابة الموارد البشرية» ومحضر اجتماع 24 أكتوبر 2026 والتوضيحات اللاحقة. ليست نسخة إنتاجية، ولا تُرفع إلى الإنترنت أو تُستخدم مع معلومات موظفين فعلية.

## التشغيل

يتطلب Python 3.9 أو أحدث دون أي مكتبات إضافية:

```bash
cd ehkam-portal
python server.py
```

افتح `http://127.0.0.1:8765` من نفس الجهاز.

| الحساب | اسم المستخدم | كلمة المرور التجريبية |
|---|---|---|
| الإدارة | admin | Admin@123 |
| المشرف | manager | Manager@123 |
| الموظف | employee | Employee@123 |

عند بدء التشغيل أول مرة تُنشأ قاعدة SQLite محلية مع شركة تجريبية وثلاثة موظفين. حذف ملف `ehkam_demo.sqlite3` يعيد بيانات الاختبار من الصفر (وسيفقد أي تعديلات سابقة).

## ما يعمل في هذه النسخة

- تسجيل دخول تجريبي ببصمات كلمات مرور PBKDF2، جلسات محلية HttpOnly، وثلاث صلاحيات.
- قائمة الشركات، إضافة شركة، أرشفة واسترجاع بتأكيد كلمة مرور المسؤول، مع سجل الإجراء والوقت.
- عرض وإضافة وتحديث ملفات الموظفين ورواتبهم وبدلاتهم وجداول دوامهم وربط المشرف.
- عزل المعلومات في استعلامات الخادم حسب المستخدم، مع صلاحية الإدارة الشاملة.
- تقديم 11 نوعًا من الطلبات، رقم EH تسلسلي، مسار طلبات واعتماد ورفض، والانتداب من المشرف للموظف.
- حساب الحد الأقصى للسلفة = إجمالي الراتب × 35% × **الأشهر التقويمية المكتملة المتبقية**، والتحقق منه عند إنشاء الطلب.
- تقدير استحقاق الإجازة في الأشهر المكتملة، عرض المتراكم والمكتسب والإجمالي وخصم الإجازة السنوية المعتمدة وإعادة الرصيد عند إلغائها.
- احتساب أيام الطلب وفق أيام العمل المحددة في جدول الموظف (0 الاثنين حتى 6 الأحد).
- تصحيح بصمة معتمد يولد حضورًا بالوقت المحدد في جدول الموظف داخل النموذج.
- عرض سجل البصمة، البحث بالفترة، وCSV للموظفين يفتح في Excel، وسجل عمليات الإدارة.
- تصميم عربي متجاوب مع عناوين رئيسية ثنائية اللغة للتجربة.

## غير جاهز للإنتاج / قيد التصميم

- **التحقق الجغرافي:** تسجيل حضور الموظف معطل عمدًا، إلى حين تعريف نطاقات المواقع والتحقق الموثوق من الموقع على الخادم، ومراعاة التحايل وإذن الوصول.
- **حماية الإنتاج:** جلسات محفوظة مؤقتًا في الذاكرة، لا توجد حماية CSRF أو قيود محاولات تسجيل الدخول أو 2FA أو إدارة مستخدمين/أدوار كاملة، ولا نظام نسخ احتياطي مُدار أو تشغيل عبر HTTPS؛ جميعها مطلوبة قبل الاستضافة.
- **الإشعارات والمرفقات:** لا توجد بعد خدمة البريد/SMS، رفع مستندات حقيقي أو استعادة كلمة المرور بالهاتف والبريد.
- **النسخة الإنجليزية:** التبديل يغير اتجاه الصفحة والعناوين الأساسية فقط، وليس ترجمة كامل المحتوى.
- **الملفات المالية:** لا توجد مسيرات رواتب أو خصومات راتب وغياب أو تسوية نهاية خدمة؛ مذكورة ضمن مطالب لاحقة/قواعد تحتاج اعتماد.
- **سياسات الإجازات:** لا يوجد ترحيل تلقائي عند تجديد العقد أو حساب معقد لتداخل أيام الراحة والعطلات الرسمية؛ المعادلة الحالية للأشهر *المكتملة* ومحددة باثني عشر شهرًا، لذلك لا تعبر عن كل سياسات الشركات.
- **سياسات السلف:** مدة المنع قبل نهاية العقد (30/60 يومًا) لم تحسم؛ لا تطبق بشكل تلقائي. استخدام الأشهر المكتملة دون الأجزاء قرار تجريبي يحتاج اعتماد.
- **مسار الطلب:** حدود صلاحيات إلغاء المعتمد وتغيير حالاته ما زالت قابلة للمراجعة. الإدارة تستطيع إدارة الطلبات التجريبية. لا يوجد سجل تفصيلي منفصل لكل حالة طلب غير سجل الأحداث العام.
- **التقارير:** CSV أولي، ولا يوجد مولد PDF أو XLSX وتقارير مجمعة شاملة بعد.
- **صلاحيات المستخدمين:** حسابات الاختبار ثابتة؛ إضافة مستخدم وتعيين حساب لموظف جديد تحتاج واجهة وإجراءات تحقق إضافية.

## بيانات الاختبار والخصوصية

لا تنشر كلمات المرور المعروضة ولا بيانات الاختبار على خدمة عامة. لإطلاق نسخة حقيقية: تصميم مخطط مستقل للاستخدام الإنتاجي، بناء إجراءات المصادقة والتفويض، قيود قواعد البيانات، ملفات آمنة، نسخ احتياطية، اختبارات وحدات وتكامل، وأمان HTTPS والخوادم.
