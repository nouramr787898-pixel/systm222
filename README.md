# إحكام الأعمال — واجهة عرض GitHub Pages

هذا المشروع نسخة تفاعلية **للعرض فقط**؛ يعمل على GitHub Pages دون خادم. ضع `index.html` في جذر المستودع (أو في مجلد النشر المحدد) ليظهر التصميم بشكل صحيح.

* اختيار الحساب في صفحة الدخول يقوم بالتبديل بين واجهات الإدارة والمشرف والموظف (ليس نظام مصادقة).
* جميع الأسماء والأرقام والمواقف بيانات تمثيلية لا تمثل موظفين حقيقيين.
* بعض الأزرار تجريبية فقط، ولا توجد قاعدة بيانات أو عزل بيانات حقيقي أو بصمة جغرافية أو إرسال إشعارات.
* **لا تستخدم هذه النسخة لبيانات حقيقية أو عمليات إنتاجية.**
* لتنفيذ البوابة الحقيقية، يلزم استضافة Backend آمنة وقاعدة بيانات وإدارة جلسات وصلاحيات على الخادم وربط نطاقات العمل وتدقيق الضوابط.
