# تحديث استعادة كلمة المرور عبر Authevo WhatsApp

- الشاشة الآن للموظف فقط وبخيار واتساب واحد؛ لم يتم حذف عنوان البريد من بيانات الموظف أو من أقسام المنصة الأخرى.
- أضف إلى Railway > systm222 > Variables متغير `AUTHEVO_API_KEY` بقيمة المفتاح `sk_...` من لوحة Authevo. لا تضع المفتاح داخل GitHub.
- افتح https://dashboard.authevo.dev وسجل حسابًا ووثّق رقم حسابك وفق التعليمات؛ تبدأ حصة 50 تحقق مجاني ناجح بعد هذا التوثيق. الدعم على الرقم المشترك متاح وفق قائمة الدول عند المزود، فتأكد من دعم السعودية قبل استعمالها.
- كل موظف يحتاج رقم واتساب صحيح بصيغة دولية +20 / +966 محفوظًا في حسابه بواسطة المدير.
- بعد رفع ملفات هذه الحزمة في جذر GitHub سيتولى Railway إعادة النشر؛ اختبر فقط بحساب موظف تجريبي وبدون بيانات حقيقية.
- الرمز من 6 أرقام وينتهي بعد 10 دقائق؛ الخادم لا يسمح بالتغيير إلا إذا أعاد Authevo `data.verified = true`.
- إن فشل إرسال واتساب، لا ينتقل النظام إلى خطوة إدخال الرمز، وتظهر رسالة خطأ عامة.
- مهم: النسخة ليست جاهزة للإنتاج: ما زالت تستخدم SQLite بلا Volume دائم، وحسابات تجريبية معروفة، وتتطلب تأمين الجلسات والصلاحيات وفحصًا شاملًا. لا ترفع بيانات موظفين حقيقية.
- Authevo ليس مجانيًا للأبد، والحصة المجانية محدودة؛ بعد نفادها تحتاج خدمة مدفوعة أو بديلًا.
